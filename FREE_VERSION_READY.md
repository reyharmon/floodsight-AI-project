### Google Maps Version:
```typescript
// Needs this:
<LoadScript googleMapsApiKey={process.env.API_KEY}>
  <GoogleMap ...>
    <Marker ... />
  </GoogleMap>
</LoadScript>

// Requires:
✅ API key
✅ Credit card
✅ .env.local file
✅ Google Cloud setup
```

### OpenStreetMap Version:
```typescript
// Just this:
<MapContainer center={[-6.2088, 106.8456]} zoom={11}>
  <TileLayer url="https://..." />
  <CircleMarker ... />
</MapContainer>

// Requires:
✅ Nothing! Just works!
```

**Simpler code, zero config!** 🎉

## 💡 **Pro Tips**

### Customize Map Style:
Change `TileLayer` URL in `Dashboard.tsx`:

```typescript
// Dark theme (current)
url="https://{s}.basemaps.cartocdn.com/dark_all/{z}/{x}/{y}{r}.png"

// Light theme
url="https://tile.openstreetmap.org/{z}/{x}/{y}.png"

// Satellite
url="https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}"
```

See more: https://leaflet-extras.github.io/leaflet-providers/preview/
